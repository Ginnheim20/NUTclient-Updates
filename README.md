# NUTclient Launcher

Der Launcher für Minecraft mit NUTclient: Profile, Mods, Server-Hub, YouTube-Raum und mehr.

## Herunterladen und installieren

1. Die neueste Version unter **[Releases](https://github.com/Ginnheim20/NUTclient-Updates/releases/latest)** öffnen.
2. Unter **Assets** die Datei `NUTclient-Launcher_<Version>_x64-setup.exe` herunterladen.
3. Die Datei starten. Windows warnt eventuell mit „Der Computer wurde durch Windows geschützt“: auf **Weitere Informationen** und dann **Trotzdem ausführen** klicken. Das Programm ist noch nicht mit einem Herausgeber-Zertifikat signiert.
4. Der Launcher aktualisiert sich danach selbst, wenn es eine neue Version gibt.

Beim ersten Start werden Java und Minecraft automatisch geladen. Für Windows 10 und 11 (64 Bit).

## Anmelden

Der Microsoft-Login ist in dieser Version noch nicht eingerichtet. Zum Spielen einfach einen **Offline-Namen** eingeben. Auf Servern mit Online-Modus kann dann allerdings kein Beitritt klappen.

## Hinweis

Die Datei `latest.json` und die Installer in den Releases sind für die automatischen Updates gedacht. Änderungen am Launcher finden im Quellcode statt, nicht in diesem Repository.
